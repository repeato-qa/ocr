# Example Electron

## Getting Started

```sh
cd ../../.. && npm install
cd packages/electron/example
npm run start
```

## Compare Main Vs Renderer

```sh
npm run benchmark
```

## Smoke Test

```sh
npm run test:smoke
```

## Packaged Smoke Test

```sh
npm run test:smoke:packaged
```

## Asset Regression Tests

```sh
npm run test:assets
```
